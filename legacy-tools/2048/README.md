# 🧊 2048

> 经典滑动合并数字游戏，相同数字相加，挑战 2048！

## 🎮 玩法

- **方向键** 或 **滑动屏幕** 移动所有数字方块
- 相同数字相撞会合并成它们的和
- 每次有效移动后随机生成一个 **2** 或 **4**
- 目标：拼出 **2048**！

## ✨ 特点

- 彩色半透明果冻材质，自动跟随系统浅色 / 深色主题
- 滑行拉伸、沿移动方向惯性回弹、双块接触挤压融合动画，支持系统减少动态效果设置
- 方向键、WASD、触屏与鼠标划动，快速操作时缓存最近一个方向
- 加分提示独立成浮动的「+N」气泡：连着得分时逐个向上堆叠、同时可见，连得越多显示越快
- **断点续玩**：每步自动存档到本地，刷新页面或关掉浏览器后回来，接着上次的棋盘继续
- 自适应棋盘，手机页面可正常滚动
- **双排行榜**：本地「我的最佳表现 TOP 10」+ 登录用户「全站 TOP 30」
- 每位用户只记录历史最高分；游戏结束与中途弃局都会上报，取较大值
- 未登录也能玩，成绩会暂存并在登录后自动补报；后端不可用时静默降级
- 随时重新开始

## 🛠️ 技术

纯 HTML + CSS + JavaScript（原生 ES Module），无任何依赖。

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构、共享登录容器、双 Tab 榜单 |
| `style.css` | 主题变量、动画、榜单与登录样式 |
| `engine.js` | 纯函数：合并 / 结束判定 |
| `game.js` | 游戏状态机、动画、本地存储；派发 `game2048:score` 事件 |
| `leaderboard.js` | 独立模块：登录态、成绩上报、TOP 30 拉取与渲染 |

`game.js` 只派发 `game2048:score` 事件，不依赖网络与登录 SDK，因此排行榜模块缺失时游戏仍完全可玩。

### 本地存储

| 键 | 内容 |
|---|---|
| `2048_bestScore` | 历史最高分 |
| `2048_leaderboard` | 本机 TOP 10 成绩 |
| `2048_savedGame` | 未结束的一局（棋盘 + 分数），每步自动覆盖；新游戏或游戏结束时清除 |

`2048_savedGame` 损坏或为空时直接忽略，按新游戏处理，不会白屏。

### 后端接口（API 项目）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/game2048/leaderboard` | 公开，前 30 名 + 登录用户的「我的排名」 |
| POST | `/api/game2048/score` | 需 Token，上报本局分数，服务端 `GREATEST` 取最大 |

数据表 `game_2048_scores` 由 `API/migrations/022_create_game_2048_scores.js` 创建，
上线前需在服务器执行 `node migrations/run.js up`。访客不参与排名。

## 本地验证

在 `games/` 目录运行 `node --test tests/2048-*.test.js` 验证合并规则与动画生命周期。
运行 `npm run build` 后，`dist/2048/` 是完整静态页面，无额外运行时依赖。
