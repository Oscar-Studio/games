# 🧠 心算记忆

> 看算式、记答案，按难度倒推前 N 轮的答案，算式复杂度随轮次递增！

## 🎮 玩法

- 屏幕上显示一个算式，你需要心算出答案并记住
- 从第 `level+1` 轮起，每轮要求你输入 `level` 轮前的答案
- 答错即游戏结束，坚持越久分数越高
- 算式复杂度随轮次递增：
  - 第 1-5 轮：一位数加减
  - 第 6-10 轮：两位数加减
  - 第 11-15 轮：一位数乘法
  - 第 16 轮及以上：混合运算（含乘法 + 加减）

## ✨ 特点

- 10 级难度，覆盖新手到高阶训练
- 训练工作记忆 + 心算双重能力
- 各级独立最佳成绩，自动保存到本地
- 无限题库，永不重复
