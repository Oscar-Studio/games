# 数独 Sudoku

> 经典 9×9 数独，5 级难度，每难度 10-20 题，按需生成唯一解。

## 玩法

- 9×9 宫格，每行/列/宫内数字 1-9 不重复
- 点击格子，输入数字 1-9（键盘或屏幕均可）
- **笔记模式**：开启后在空格内输入候选数（不会覆盖已有数字）
- **错误检测**：输入与同行/列/宫冲突时数字标红，错误数 +1
- **提示**：随机揭示一个空格答案，每局 3 次
- **撤销**：Shift+Z 或工具栏按钮
- 完成所有格子且全部正确即通关，记录用时与错误数

## 难度

| Lv | 名称 | 所需技巧 | 题数 |
|----|------|----------|------|
| 1 | 入门 | 显性唯一，开局至少有 8 格可以直接确定 | 10 |
| 2 | 简单 | 隐性唯一 | 12 |
| 3 | 中等 | 区块排除 | 15 |
| 4 | 困难 | 显性数对 | 15 |
| 5 | 专家 | 显性三数集或 X-Wing | 20 |

每题都有唯一解。难度由逻辑求解过程中实际用到的最高阶技巧决定。

## 键盘快捷键

| 键 | 操作 |
|----|------|
| 1-9 | 输入数字 |
| N | 切换笔记模式 |
| Backspace / 0 | 清除 |
| Shift+Z | 撤销 |
| H | 提示 |
| 方向键 | 移动选中 |

## 技术

- 纯静态 HTML/CSS/JS，零依赖
- 题目生成：回溯生成终盘，随机逐格移除线索，检查唯一解并按目标技巧筛选。达到尝试上限时，随机变换同级验证题型。
- 本地存储：每难度历史最佳（用时 + 错误数）

## 本地运行

```bash
# 在 games/ 根目录
npm run dev
# 在 Vite 打印的本地地址后加 /数独/
```
