# 🔐 猜数字 Bulls and Cows / Mastermind

> 经典推理破译游戏，两个模式（1A2B 数字 + Mastermind 颜色），3 档固定难度，根据反馈轮迭代推理出隐藏序列。

## 🎮 玩法

- **目标**：在限定次数内猜出隐藏的序列
- **反馈**：
  - **1A2B 模式**：`XAYB` — `A` = 数字对且位置对，`B` = 数字对但位置错。例：答案 `1234`，猜 `1243` → `2A2B`
  - **Mastermind 模式**：4-5 个反馈钉 — ⚫ 颜色对位置对 / ⚪ 颜色对位置错 / 🔘 不在答案中
- **胜利**：用最少的次数命中序列
- **失败**：用尽次数时揭晓答案

## 🌟 模式

| 模式 | 元素 | 数量 | 重复 |
|------|------|------|------|
| 1A2B 数字 | 0-9 | 3-5 位 | ❌ 不允许 |
| Mastermind 颜色 | 6 色（红橙黄绿蓝紫） | 3-5 位 | ✅ 允许 |

顶部 `1A2B` / `Mastermind` Tab 切换。切换会开启新的一局。

## 📊 难度

| 等级 | 名称 | 位数 | 次数 |
|------|------|------|------|
| 易 | 入门 | 3 位 | 6 次 |
| 中 | 标准 | 4 位 | 8 次 |
| 难 | 硬核 | 5 位 | 10 次 |

## ⌨️ 快捷键

| 键 | 操作 |

| `0-9` (1A2B) | 填入数字 |

## 🧠 推理技巧

1. **先求稳再求优** — 第一轮用含 Spread 数字的猜测（如 0、4、8 这种差值大的），最大化信息量
2. **少用类似数字** — 同色或相邻数字（如 1、2、3）会互相干扰反馈
3. **用 XAYB 推算** — 例如答题 `1234`，猜 `1357` 得 `1A0B` → 说明 `1` 位置对，可用「排除法」逐步锁定
4. **B 数计数** — 1A2B 的 `B` 是数字对但位置错，可换位尝试
5. **Mastermind 考虑重复** — 反复选同一颜色直到 `B` 反馈为 0，可定位重复色

## ✨ 特点

- **零依赖** — 纯 HTML + CSS + 原生 JavaScript
- **响应式** — 移动端单列布局，桌面端居中
- **localStorage** — 按 (模式 × 难度) 记录最佳成绩
- **状态保留** — 切换 tab / 难度自动开新局，避免跨模式状态污染
- **色盲友好** — Mastermind 6 色都配有形状图标（●▲■★◆⬟）

## 🛠️ 技术

- 评分算法：经典 Bulls and Cows（`bulls = Σ(guess[i]===secret[i])`, `cows = Σmin(countGuess, countSecret) - bulls`）
- 序列生成：1A2B 用 Fisher-Yates 洗牌后切片，Mastermind 直接随机抽样
- DOM 渲染：纯 DOM 操作，无框架
- 样式：CSS 变量 + 暗色玻璃主题，沿用现有 games/ 数独 / 二十四点的设计语言
