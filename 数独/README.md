# 数独 Sudoku

> 经典 9×9 数独，5 级难度，每难度 10-20 题，按需生成唯一解。

## 玩法

- 9×9 宫格，每行/列/宫内数字 1-9 不重复
- 点击格子，输入数字 1-9（键盘或屏幕均可）
- **笔记模式**：开启后在空格内输入候选数（不会覆盖已有数字）
- **错误检测**：输入与同行/列/宫冲突时数字标红，错误数 +1
- **提示**：随机揭示一个空格答案，每局 3 次
- **撤销**：Shift+Z 或工具栏按钮
- 完成所有格子且全部正确即通关，记录用时与错误数

## 难度

| Lv | 名称 | 挖空范围 | 题数 |
|----|------|----------|------|
| 1 | 入门 | 36-40 | 10 |
| 2 | 简单 | 42-46 | 12 |
| 3 | 中等 | 48-50 | 15 |
| 4 | 困难 | 52-55 | 15 |
| 5 | 专家 | 56-58 | 20 |

每题均保证**唯一解**，通过求解器验证生成。

## 键盘快捷键

| 键 | 操作 |
|----|------|
| 1-9 | 输入数字 |
| N | 切换笔记模式 |
| Backspace / 0 | 清除 |
| Shift+Z | 撤销 |
| H | 提示 |
| 方向键 | 移动选中 |

## 技术

- 纯静态 HTML/CSS/JS，零依赖
- 题目生成：回溯填终盘 + 中心对称挖洞 + 求解器验证唯一性
- 难度评估：挖空数 + 技巧识别器（基础排除 / 显性数对 / X-Wing / 剑鱼 / XY-Chain）
- 本地存储：每难度历史最佳（用时 + 错误数）

## 本地运行
